# Seekai

A fast, minimal browser extension that replaces your new tab page with a powerful search interface for bookmarks and open tabs.

## Features

- **Instant Search** - Fuzzy search across bookmarks and tabs
- **Smart Focus** - Start typing anywhere to search (no need to click)
- **Usage Tracking** - Most-used bookmarks appear first
- **9 Beautiful Themes** - Including Rosé Pine, Sakura Night, and more
- **Keyboard Navigation** - Navigate with arrow keys, Enter, and Escape
- **Google Fallback** - Press Enter with no results to search Google
- **Custom Bookmarks** - Add quick-access bookmarks via settings

## Installation

### Chrome / Brave / Edge

1. Download or clone this repository
2. Open your browser and navigate to:
   - **Chrome**: `chrome://extensions/`
   - **Brave**: `brave://extensions/`
   - **Edge**: `edge://extensions/`
3. Enable **Developer mode** (toggle in top-right corner)
4. Click **Load unpacked**
5. Select the `seekai-extension` folder
6. Open a new tab - Seekai is now your new tab page!

### Firefox

1. Download or clone this repository
2. Open Firefox and navigate to `about:debugging#/runtime/this-firefox`
3. Click **Load Temporary Add-on**
4. Navigate to the `seekai-extension` folder and select `manifest.json`
5. Open a new tab - Seekai is now your new tab page!

## Usage

- **Start typing** - Search activates automatically when you type
- **Arrow keys** - Navigate results
- **Enter** - Open selected bookmark/tab
- **Escape** - Clear search
- **Ctrl/Cmd + K** - Focus search bar
- **Click ⚙️** - Open settings to add bookmarks or change themes

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Type anything` | Auto-focus search and filter results |
| `↑` / `↓` | Navigate results |
| `Enter` | Open selected item |
| `Esc` | Clear search |
| `Ctrl+K` / `Cmd+K` | Focus search bar |
| `Tab` / `Shift+Tab` | Navigate results |
